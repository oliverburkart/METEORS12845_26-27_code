### Driver 1 (Chassis & Movement)

* **Right Stick:** Rotation (Turning)
* **Right Bumper:** April Tag lock
* **Left Bumper:** Slow mode toggle

### Driver 2 (Scoring & Mechanisms)

* **Y Button:** Shoot

## 🛠️ Software Workflow
We use a **Git Feature Branch** workflow to keep our `main` trunk stable:
1. Create a new branch for your feature (`git checkout -b feature-name`).
2. Code, test, and commit your changes.
3. Push your branch to GitHub and open a **Pull Request**.
4. A teammate or mentor must manually review and approve the code before it is merged into `main`.
